ВАРИАНТ 2: ДЕПЛОЙ В TELEGRAM (10 минут)

  Шаг 1: Создайте бота через @BotFather
    • Telegram → @BotFather → /newbot
    • Скопируйте токен
  
  Шаг 2: Разместите на GitHub Pages (бесплатно)
    • Создайте репозиторий на github.com
    • git push код (index.html, styles.css, game.js)
    • Settings → Pages → Enable
    • URL: https://username.github.io/battleship-miniapp/
  
  Шаг 3: Зарегистрируйте Mini App
    • @BotFather → /newapp
    • Укажите ваш GitHub Pages URL
  
  Шаг 4: Запустите бота
    • cp .env.example .env
    • Впишите TELEGRAM_BOT_TOKEN и WEBAPP_URL
    • python3 bot.py
  
  Шаг 5: Играйте в Telegram! 🎉
