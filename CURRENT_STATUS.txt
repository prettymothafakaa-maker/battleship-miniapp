🚀 БЫСТРЫЙ ЗАПУСК (3 ШАГА)
════════════════════════════════════════════════════════════════

ШАГ 1: Создайте бота в @BotFather
  /newbot
  Имя: Морской Бой
  Username: battleship_yourname_bot
  → Скопируйте токен

ШАГ 2: Включите Inline режим
  /setinline
  [выберите бота]
  Inline placeholder: 🚢 Морской Бой

ШАГ 3: Разместите игру
  A) GitHub Pages:
     - Создайте репозиторий
     - Загрузите webapp.html
     - Settings → Pages → Deploy
     - URL: https://username.github.io/repo/webapp.html

  B) Ngrok (для теста):
     ngrok http 8080
     → Скопируйте https URL

ШАГ 4: Настройте и запустите
  cd ~/battleship-miniapp
  cp .env.example .env
  nano .env  # Укажите TELEGRAM_BOT_TOKEN и WEBAPP_URL
  ./quickstart_inline.sh

🔧 ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ
════════════════════════════════════════════════════════════════

FRONTEND (webapp.html):
  - HTML5 + CSS3 + Vanilla JavaScript
  - Telegram WebApp SDK v6.0+
  - Адаптивная сетка 10×10
  - CSS переменные для темы Telegram
  - Touch-оптимизированный интерфейс
  - Минифицированный код

BACKEND (bot_inline.py):
  - python-telegram-bot v20+
  - InlineQueryHandler для Inline режима
  - CommandHandler для команд (/start, /play, /help)
  - WebAppDataHandler для результатов игры
  - Graceful error handling

ИНТЕГРАЦИЯ:
  - tg.ready() - инициализация WebApp
  - tg.expand() - полноэкранный режим
  - tg.MainButton - нативная кнопка внизу
  - tg.showAlert() - системные уведомления
  - tg.sendData() - отправка результатов
